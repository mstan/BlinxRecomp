# Documentation images

`adaptive-gameplay.jpg` is an unchanged screenshot captured and supplied by
Matthew Stanley during a Blinx widescreen development playtest. It illustrates
the preview; it is not a capture of every later build or proof of all features.

`alpha-16x9.png` (1280x720) and `alpha-21x9.png` (1680x720) are unedited
native TCP screenshots captured October 29, 2026 from the current RAM-cache
build in Stage 1. Adaptive aspect, 1080p internal rendering, FXAA and 8x
filtering are enabled; simulation timing is original. The run used a copied
native save in an isolated profile, without guest-memory cheats. The captures
illustrate presentation, not complete campaign qualification.

Original Blinx: The Time Sweeper visuals belong to Artoon, Microsoft and the
applicable rights holders. The repository's source-code license does not
relicense the depicted game assets. This screenshot is documentation, not a
redistributable game-data package.

The October 29 PNG captures were re-exported as opaque RGB after discovering
that the ignored framebuffer alpha had been saved as web transparency. Every
RGB sample is identical to the original capture; no color/contrast adjustment
was applied. Older transparent exports remain only in Git history.

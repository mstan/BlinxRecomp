# October 23 playtester preview

This preview includes the accepted stage-entry presentation improvements and
independent **Invert horizontal camera** and **Invert vertical camera** toggles
under Mods. Both inversion toggles start off. Gameplay retains its original
timing; blended higher-rate presentation is a separate visual option.

The owner has checked that all campaign stages load quickly with the latest
presentation change. That is a stage-loading observation, not exhaustive
gameplay or performance qualification on every PC.

## Known issues and useful feedback

- The damaged-enemy health circle can still appear too wide in widescreen.
  Its correction remains in progress; this preview does not claim it fixed.
- Brief hitches may remain. Note the stage and action rather than assuming
  every hitch is background machine load.
- Assisted campaign coverage uses cheats and teleports. Natural encounters,
  optional routes and all save-storage combinations have not been exhausted.

If a problem occurs, keep the session under `data/diagnostics` and send its
`report.json` with the stage and action. Optional controller-input recording
can help reproduce it; see
the diagnostics instructions in the package. Do not include your original
game files, kernel dump, EEPROM or console keys in a public report.

## Setup and updating

Extract the complete ZIP into a writable folder and open **Start Game.cmd**.
Choose **Skip** for a new local console, then select your own matching
extracted `default.xbe` on the main screen. Keep its full asset tree together.
No compiler, kernel dump, EEPROM or HDD image is needed for this simple path.

When replacing an existing package, preserve its `data` folder and any
separately selected save storage and console profile. Native in-game saves
are persistent progress; build-specific save states are disposable.

Matching project and prepared dependency source is included under `source/`.
The package contains no original game assets, console dumps or personal saves.

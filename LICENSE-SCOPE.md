# Scope

The copied official PolyForm Noncommercial 1.0.0 text applies to owner-original
work in this game repository under the existing Xbox ecosystem policy.
Third-party source, dependencies, generated original code and owned game inputs
retain their existing terms. Their inclusion is not authorized by this file.
The separately credited launcher cover artwork retains the terms recorded in
[its attribution notice](assets/launcher/NOTICE.md).

This repository currently composes the **private reference pilot**. Its pinned
framework's [license scope](xboxlle/LICENSE-SCOPE.md), including the unresolved
combined-executable restrictions and exclusion of GPL implementations from the
intended non-GPL shipping product, remains in force. Private visibility is not
a new licensing permission. No executable release is part of this repository
setup. Owned binaries, media, EEPROMs, captures and generated code remain local.
